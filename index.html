Flagship Project • Team of 4

Rover Crack Inspector

Key achievement

An AI-powered pipeline inspection rover. An ESP32-CAM streams live video over WiFi, a Python backend runs a crack-detection model, and a web dashboard shows the live camera feed and detected cracks.

My Exact Role (Software Side)

I owned the software side. My 3 teammates built the rover hardware.
I trained the crack-detection AI: a YOLOv8 image classifier trained in Python on Google Colab using 40,000 Kaggle images (20,000 crack, 20,000 no crack), 50 epochs, 99.9% validation accuracy on that dataset. Real pipes look different, so retraining on rover photos is planned. I developed the backend and the frontend dashboard using HTML, CSS, JavaScript and Python. The dashboard displays the camera feed and flags detected cracks with automatic snapshot saving and SQLite timestamp logging. I wrote the ESP32 firmware file. Do NOT claim any hardware design or assembly as mine.

Python FastAPI SQLite WebSocket HTML CSS JavaScript YOLOv8 PyTorch Google Colab Arduino C/C++
